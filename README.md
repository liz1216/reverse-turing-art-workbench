# 反转图灵 · 美术摄影工作台

独立的五视图美术工作台：环幕空间、三人黑底、三人白底、双人电影、单人镜头。

通过 GitHub Pages 打开，输入项目负责人提供的密码，然后选择负责人私下交付的头模和贴图素材文件夹。文件只在本机浏览器读取，不上传服务器。

可调灯光、材质、整体调色、头部位置和机位，并导出参数、截图或无声视频。H 隐藏界面，Esc 恢复；环幕的左侧虚拟制片参数可用右侧“空间参数 V”或 V 键打开。

本仓库仅存放静态网页、加密的工作台程序、第三方依赖和公开地面材质，不包含头模、皮肤或眼睛贴图。访问密码由项目负责人私下提供，不保存在仓库中。

本项目为独立部署，不修改或替换其他美术工作台。
